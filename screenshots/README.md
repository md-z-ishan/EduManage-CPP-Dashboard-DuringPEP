# Terminal CLI Choices & Dashboard Screenshots

Here is a short explanation of the terminal choices, along with the screenshots from the project.

## CLI Menu Choices (Short Explanation)
1. **Insert new student**: Add a new student's details (Roll No, Name, Marks).
2. **Search for a student**: Find a student by their Roll No using BST and view their report.
3. **Print all students**: View a list of all students sorted by their Roll No (Code Ascending).
4. **Print students (>= percentage)**: Filter and view top students above a certain percentage.
5. **Sort and Print by Name**: View all students alphabetically sorted by their Name (Merge Sort).
6. **Sort and Print by Grade**: View the merit list sorted by percentage (Quick Sort).
7. **View Class Statistics**: See the class average, highest, and lowest percentages.
8. **Quit**: Exit the terminal application.
